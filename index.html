How this website works

GD Searcher is a small interface for finding Geometry Dash levels and player profiles. Use the navigation buttons at the top to switch between pages; only the selected panel is shown.

  • Home: Introduction and the featured image.
  • Search: Enter a level or other search term and press SEARCH. The current page provides the input interface; it does not yet connect to a search service.
  • Profiles: A profile search field for finding players. It is currently a visual input and is not connected to player data.
  • About: Brief information about GD Searcher.
  • Configuration: Choose Spanish or English and switch between dark and light appearance.
